images `og.jpg` / `og-de.jpg`), privacy policy, terms of service and legal notice of the iPhone game Idle Transport
Corp, served by GitHub Pages: https://mario-coder-apps.github.io/idletransportcorp-legal/

privacy.html, terms.html and impressum.html come from `store/site/` of the game project: copy them here, commit, push.

with `--delete` (it would remove the German page and the images). The FAQ in the pages' JSON-LD must match the
visible FAQ.
